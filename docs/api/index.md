# API Reference

This section documents all available LubeLogger API endpoints and their PowerShell module implementations.

## Overview

The API Reference is organized by resource type:

- **[Vehicles](vehicles.md)** - Vehicle management and information
- **[Odometer Records](odometer-records.md)** - Mileage tracking and readings
- **[Service Records](service-records.md)** - Maintenance and service history
- **[Repair Records](repair-records.md)** - Repair work and costs
- **[Gas Records](gas-records.md)** - Fuel consumption and costs
- **[Reminder Records](reminder-records.md)** - Maintenance reminders and alerts
- **[Plan Records](plan-records.md)** - Planned maintenance and upgrades
- **[Equipment Records](equipment-records.md)** - Vehicle equipment and modifications
- **[Supply Records](supply-records.md)** - Parts and supplies inventory
- **[Tax Records](tax-records.md)** - Tax deductions and records
- **[Notes](notes.md)** - General notes and documentation
- **[Miscellaneous](miscellaneous.md)** - Calendar, extra fields, and utility endpoints
- **[Admin](admin.md)** - Administrative operations

Each endpoint section includes the HTTP method, required/optional parameters, request body structure (for POST/PUT), and any available PowerShell function wrapper.
